# Deepak Kumar — Developer Portfolio

A responsive, single-page developer portfolio built with **HTML5, CSS3, and vanilla JavaScript**, using a dark navy theme with cyan accents.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Dark navy and cyan visual theme
- Sections for About, Skills, Experience, Key Contributions, Projects, and Contact
- Mobile navigation menu
- Smooth in-page navigation and scroll-reveal animations
- Email and phone contact links
- No frontend framework or build tools required

## Project Structure

```text
deepak-portfolio/
├── index.html   # Page content and structure
├── style.css    # Styling, layout, responsive rules, and animations
├── script.js    # Mobile navigation, active section, and reveal effects
└── README.md    # Project documentation
```

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

For local development, you can also open the folder in Visual Studio Code and use the **Live Server** extension. No package installation is needed.

## Customize Before Publishing

- Replace the `DK` profile placeholder in `index.html` with your own professional photo if desired.
- Update the GitHub and LinkedIn links to your actual profile URLs.
- Add your resume PDF and update the **Request CV** link if you want visitors to download it directly.
- Verify all project descriptions and list only work you are allowed to share publicly.
- Keep contact details up to date.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `deepak-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes publishing, use the URL shown in the Pages settings.
